English · [中文](./README.zh.md)

A collection of agent skills. Install as plain files to `.agents/skills/`, hackable.

## Installation

```bash
npx skills add CoolTea001/cool-skills        # all skills
npx skills add CoolTea001/cool-skills --skill cool-test  # single skill
npx skills update                             # update
```

## Skills

| Skill | Description |
|-------|-------------|
| [cool-test](./skills/cool-test/SKILL.md) | A web automated testing Skill that converts test cases / requirements / source in any format into a JSON test suite, runs tests, and finally generates an editable offline report. |
