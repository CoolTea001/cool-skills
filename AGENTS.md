# AGENTS.md

## Commit Rules

1. Before commit, check for temp files, large files, and sensitive content (keys, tokens, .env).
2. Commit messages must be in English.
3. Do not execute git commit / git push without the user's explicit request.

## Docs Language

1. `.md` files default to English.
2. Add `.zh.md` as Chinese supplement.
3. `.md` and `.zh.md` must be kept in sync.
