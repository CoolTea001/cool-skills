一组对我有用的 Skills，或许对你也有用。

## 安装

```bash
npx skills add CoolTea001/cool-skills        # 全部
npx skills add CoolTea001/cool-skills --skill cool-test  # 单个
npx skills update                             # 更新
```

## Skills

| Skill | 说明 |
|-------|------|
| [cool-design](./skills/cool-design/SKILL.zh.md) | Nuxt 设计系统，基于 Nuxt UI 与 Tailwind CSS v4，暗色模式为默认主题。用于所有 UI 实现和页面设计任务。 |
| [cool-teach](./skills/cool-teach/SKILL.zh.md) | 多课程学习工作区技能（`.coolteach`）—— 创建课程、生成冻结题型的小课，并用固定模板打开本地预览（修复单课程、样式不一致与习题 BUG）。 |
| [cool-test](./skills/cool-test/SKILL.zh.md) | 将任意格式用例 / 需求 / 源码转为 JSON 测试套件并进行测试，最后生成可编辑离线报告的 Web 自动化测试 Skill。 |
